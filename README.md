# Pulsar Detection using Machine Learning

## 📌 Problem Statement
Classify radio telescope signals as either:
- 0 → Noise
- 1 → Real Pulsar

## 📊 Dataset
HTRU2 Dataset (UCI Machine Learning Repository)

## ⚙️ Models Used
- Logistic Regression
- Random Forest Classifier

## 📈 Results
- Logistic Regression Accuracy: ~98%
- Random Forest Accuracy: ~98.2%
- Random Forest performed slightly better in recall for pulsar class.

## 🧠 Key Insight
Kurtosis_IP and Skewness_IP were the most influential features.

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
